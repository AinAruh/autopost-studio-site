Política de Privacidade

Última atualização: 21 de novembro de 2026.

Esta política descreve o funcionamento pretendido do AutoPost Studio e distingue os recursos existentes daqueles ainda em desenvolvimento.

1. Informações tratadas

O aplicativo pode armazenar localmente dados de configuração, como nomes de contas cadastradas, caminhos de pastas, regras de publicação, registros de atividade e credenciais locais de acesso. Quando as integrações oficiais forem implementadas, poderá tratar identificadores de conta e tokens de autorização fornecidos pelas plataformas, conforme as permissões aprovadas.

2. Finalidades

Os dados são usados para configurar o aplicativo, autenticar o administrador local, organizar fontes de mídia, exibir status e, quando disponível e autorizado, executar publicações solicitadas pelo usuário.

3. Armazenamento e compartilhamento

Na versão desktop atual, configurações e registros operacionais são armazenados no dispositivo do usuário. Recursos futuros de integração poderão transmitir dados necessários às APIs oficiais das plataformas escolhidas pelo usuário. Não declaramos venda de dados pessoais. Este site estático pode estar sujeito a registros técnicos do serviço de hospedagem GitHub Pages.

4. Segurança

O aplicativo utiliza controles locais e criptografia para determinados segredos, mas a segurança também depende das permissões e da proteção do dispositivo. Nunca envie senhas ou tokens por formulários públicos ou issues.

5. Controle e exclusão

Você pode remover cadastros no aplicativo, excluir os arquivos locais de dados e revogar autorizações diretamente nas plataformas conectadas. A exclusão de dados nas plataformas de terceiros segue as regras de cada serviço.

6. Crianças e terceiros

O aplicativo não é destinado à coleta intencional de dados de crianças. O usuário deve ter autorização para tratar e publicar conteúdos que envolvam outras pessoas.

7. Atualizações e contato

Esta política poderá ser atualizada à medida que novas integrações forem disponibilizadas. Para dúvidas ou solicitações relacionadas à privacidade, use o canal de contato no GitHub, sem divulgar dados sensíveis publicamente.
